A HOST LIFECYCLE YOU CAN EXPLAIN

Observation and control have different jobs.

The runtime guide matches the installed 0.3.310 type declarations. Practice implements a small scripted adapter; live mode forwards these controls to the real query handle.

Read the actual host pattern

const input = new InputQueue<SDKUserMessage>();
const q = query({ prompt: input, options });

try {
  for await (const msg of q) {
    if (msg.type === 'result') {
      // Replace the latest usage snapshot.
      latestUsage = msg.modelUsage;
    }
  }
} finally {
  q.close();
  input.close();
}

Runtime controls use q while the stream consumer remains active. See src/server/session.ts for this app’s error, timeout, and cleanup handling.

A version-specific correction

Connection health and permission are separate. Agent discovery and agent execution are separate. Reading usage and closing resources are separate.

The model change applies to subsequent responses. This lab waits between turns before changing runtime configuration.
